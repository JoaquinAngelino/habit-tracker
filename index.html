Habits are saved encrypted to data/habits.enc on this branch. It is created from the default branch on first save, so saving never redeploys the site.

A fine-grained token for this one repository with Contents: Read and write. It is sent only to api.github.com.

Encrypts your habits before they leave this device. The file is public, so anyone can try to guess it: use four or more random words. If you lose it, the data cannot be recovered.
